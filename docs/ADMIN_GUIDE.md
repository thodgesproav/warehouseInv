# Administrator guide

- **Inventory**: use Edit to change any Excel field. Save writes to the mapped workbook row and preserves other columns.
- **Requests**: mark a request ordered or complete, or add it as a zero-stock inventory row for further editing.
- **Transactions**: review successful, rejected, conflicting, and failed changes.
- **Users**: create accounts, choose Admin/Standard, and disable accounts. Reset a password by editing the user through the API until the reset control is added to the UI.
- **Settings**: remap application fields after an Excel heading rename and force synchronization.
- Product image upload accepts JPG, PNG, or WebP up to 5 MB. Clear the `Image` field and save to remove an assigned image.

Never delete the final enabled Admin account. After initial login, create a named Admin user and rotate the bootstrap password.
