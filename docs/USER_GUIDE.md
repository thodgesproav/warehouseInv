# User guide

1. Sign in.
2. Type a name, manufacturer, part number, category, or location into Search.
3. Choose **Take item**.
4. Select the quantity and confirm. If somebody changed the stock first, refresh and try again.
5. Use **Request item** when the item is not listed.
6. **My activity** shows your stock changes.

If a red synchronization message appears, you can browse the last available inventory but should not assume a stock change succeeded unless the app says **Stock updated**.
